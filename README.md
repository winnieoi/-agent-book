# 《AI 时代大学生的生存指南》

> 写给每一个在 2026 年走进教室、却被告知"你们这届不太一样"的大学生。
>
> AI 不会淘汰你，但会用 AI 的人会。这本书不教你玄学咒语，只给你一套**可执行的动作**。

---

## 写在前面：这本书怎么用

- 这是一本**工具书**，不是教科书。你可以从任意一章开始读，但建议按顺序读完"认知篇"。
- 每一章末尾都有 **本章行动清单**，不读完也能干活——直接翻到清单照着做。
- 书里提到的工具会过时，但**判断标准和动作流程**不会。过时的地方请以附录 A 的更新清单为准。
- 全书统一体例：

  ```
  开场场景  →  本章你会得到什么（3 条）  →  正文 3–4 节
  →  工具箱 / 提示词模板  →  常见坑  →  本章行动清单
  ```

## 目录

### 前言　你不是在被 AI 取代，你是在被重新定价

### 第一部分　认知篇：先搞清楚你面对的是什么

- **第 1 章　这不是一个工具，是一次分工重构**
  每一次技术革命真正改变的是什么 / 大学生被切走的到底是哪一块 / 三年后的课堂长什么样
- **第 2 章　大模型的能力边界：能做什么、做不好什么、绝对做不了什么**
  三个圆圈模型 / 幻觉从哪里来 / 它最不擅长的四件事 / 建立你的"信任校准"
- **第 3 章　能力坐标系：什么在贬值，什么在升值**
  贬值清单：记忆、格式化输出、初级检索、套路化表达 / 升值清单：提问、判断、审美、整合、交付 / 一张自测表
- **第 4 章　大学四年的杠杆策略：AI 是杠杆，不是拐杖**
  杠杆与拐杖的区别 / 四个年级各自的重心 / 一个反直觉的建议：先练"不用 AI 也能做到"

### 第二部分　学习篇：怎样学得更快，而且记得住

- **第 5 章　重建学习闭环：预习—输入—加工—输出—复盘**
  传统学习环为什么断了 / AI 适合介入的四个节点 / 费曼式提问法 / 一周学习流程模板
- **第 6 章　论文与写作：从选题到成稿**
  用 AI 找选题（以及为什么不能全信它） / 文献检索与综述的正确姿势 / 结构比文采重要 / 怎么去掉"AI 味" / 答辩准备
- **第 7 章　语言、数学、编程：找一个不会累的陪练**
  外语：沉浸式对话与错题本 / 数学：让它讲思路而不是给答案 / 编程：从抄代码到读懂代码
- **第 8 章　从收藏夹到第二大脑**
  为什么"收藏即学会"是骗局 / 三层笔记结构 / 个人知识库的搭建与检索 / 让笔记真的被用起来

### 第三部分　专业篇：把 AI 装进你的专业

- **第 9 章　设计·建筑·艺术类：概念—草图—建模—图纸—展板**
  创意阶段怎么用才不抄袭 / 方案比选与推演 / 建模与渲染的自动化 / 展板、作品集与汇报
- **第 10 章　文科·社科：调研、访谈、质性分析**
  田野与问卷的 AI 辅助 / 访谈稿的编码与主题提炼 / 论证链条的检验 / 学术规范的红线
- **第 11 章　理工科：实验、仿真、数据处理与可视化**
  文献复现与实验设计 / 数据清洗与统计分析 / 图表与论文配图 / 仿真与参数化
- **第 12 章　商科与交叉学科：分析、建模、汇报**
  行业研究与竞品分析 / 财务与数据建模 / 一份能过导师和甲方两关的 PPT

### 第四部分　工具篇：从聊天框到个人工作台

- **第 13 章　提示词不是咒语，是需求说明**
  好提示词的四个要素 / 五种常用结构模板 / 迭代比一次成型重要 / 不要背提示词
- **第 14 章　从聊天机器人到 Agent：插件、MCP 与 API**
  让 AI 连上你的文件、软件和数据 / 什么任务值得交给 Agent / 一个真实的自动化案例
- **第 15 章　把重复劳动自动化**
  识别"值得自动化"的三条标准 / 信息流的自动收集与简报 / 文件、格式、批处理的脚本化
- **第 16 章　你的个人 AI 工作台**
  设备与环境的最低配置 / 模型怎么选、订阅怎么买最划算 / 数据备份与版本管理

### 第五部分　产出篇：让努力变成看得见的资产

- **第 17 章　做一个能拿得出手的项目**
  选题：小、完整、有证据 / 项目的最小闭环 / 过程中的记录与复盘 / 从课程作业到项目
- **第 18 章　作品集与个人网站**
  作品集不是文件夹 / 叙事结构：问题—方法—结果—反思 / 个人网站的搭建与维护
- **第 19 章　竞赛、开源与社区：把努力沉淀成资产**
  竞赛的真实收益与隐形成本 / 开源贡献的第一 Pull Request / 在社区里被看见的正确方式
- **第 20 章　把作品讲出去**
  汇报的结构与节奏 / 三分钟版本与十分钟版本 / 面对提问的四类应答

### 第六部分　出路与边界篇：走远一点，也走稳一点

- **第 21 章　实习、简历与面试**
  简历的量化与取舍 / 作品集链接、GitHub、个人主页怎么排 / AI 时代的面试新问题 / 实习里真正该学的东西
- **第 22 章　考研、保研、留学与就业：选择的底层逻辑**
  四条路的真实成本 / 用 AI 做择校与信息调研 / 什么时候不该继续读书 / 决策清单
- **第 23 章　红线：学术诚信、隐私与版权**
  学校的规定通常怎么写的 / 什么算作弊、什么不算 / 引用与声明的规范写法 / 数据隐私与素材版权
- **第 24 章　别被反噬：幻觉、信息茧房、专注力与焦虑**
  交叉验证的三步法 / 推荐流如何收窄你的世界 / 与 AI 相处的心理边界 / 什么时候应该关掉它
